# zapyt.biz

Платформа запитів українською та польською: авто/мото, нерухомість, допомога, робота, знайомства.
Вхід через Telegram, контакт у запитах — лише нік Telegram (номери телефонів блокуються).

## Запуск

Потрібен лише Python 3.9+ — жодних інших залежностей.

```bash
python3 server.py --seed
```

Сайт відкриється на http://localhost:8000. Прапорець `--seed` додає демо-запити в порожню базу.

Поки бот Telegram не підключено, працює **тестовий вхід** за ніком (для перевірки на своєму комп'ютері).

## Підключення входу через Telegram

1. У Telegram відкрийте @BotFather → `/newbot` → отримайте токен і нік бота.
2. У @BotFather виконайте `/setdomain` і вкажіть `zapyt.biz` (віджет входу працює лише на цьому домені, не на localhost).
3. Скопіюйте `.env.example` у `.env`, заповніть `TELEGRAM_BOT_TOKEN` і `TELEGRAM_BOT_USERNAME`, перезапустіть сервер.

Після цього тестовий вхід вимикається автоматично. Якщо користувач запустив бота, він також
отримуватиме в Telegram сповіщення про нові відповіді на свої запити.

## SMS-підтвердження номера

Після першого входу користувач підтверджує номер телефону 6-значним кодом із SMS. Без цього він не може
створювати запити, відповідати на них і бачити контакти. Номер ніде не показується.

SMS надсилаються через Twilio: зареєструйтесь на twilio.com і впишіть у `.env` значення
`TWILIO_ACCOUNT_SID`, `TWILIO_AUTH_TOKEN`, `TWILIO_FROM`. Поки вони порожні, працює **тестовий режим**:
код показується просто у вікні підтвердження, а SMS не надсилається.

## Розміщення на сервері

Запустіть `python3 server.py` як службу (systemd) і поставте перед ним nginx або Caddy з HTTPS,
який проксіює `zapyt.biz` на `127.0.0.1:8000`. У `.env` має бути `COOKIE_SECURE=1`.
Дані лежать у теці `data/` (база `zapyt.db` і фото) — саме її треба резервувати.

## Структура

- `server.py` — сервер, API, база SQLite, перевірка підпису Telegram
- `public/` — інтерфейс: `index.html`, `styles.css`, `app.js`, `i18n.js` (усі тексти двома мовами)
- `.env.example` — налаштування
